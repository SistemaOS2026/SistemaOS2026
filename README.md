# Sistema OS — Infocel Assistência Especializada

O **Sistema OS** é um aplicativo desktop de uso pessoal e interno, desenvolvido para auxiliar no gerenciamento de ordens de serviço da Infocel Assistência Especializada.

O aplicativo é utilizado exclusivamente pelo proprietário nos computadores autorizados. As contas Google utilizadas na integração e no armazenamento dos backups pertencem ao próprio proprietário.

## Funcionalidades

- Cadastro e acompanhamento de ordens de serviço.
- Armazenamento local dos dados em banco de dados SQLite.
- Integração com o Google Drive para envio, consulta e recuperação de backups do banco de dados.
- Utilização restrita aos computadores e às contas autorizadas pelo proprietário.

## Política de Privacidade

**Última atualização: 22 de outubro de 2026**

### 1. Finalidade e uso

O Sistema OS é destinado exclusivamente ao uso pessoal e interno do proprietário da Infocel Assistência Especializada. Não é um serviço público, não é oferecido a clientes externos e não possui finalidade de comercialização de dados.

### 2. Dados tratados pelo aplicativo

O aplicativo pode armazenar localmente informações necessárias ao funcionamento das ordens de serviço, como dados de clientes, equipamentos, diagnósticos, valores e status dos serviços.

Essas informações são utilizadas para a operação da assistência técnica e permanecem sob controle do proprietário do sistema.

### 3. Integração com o Google Drive

O aplicativo utiliza a API do Google Drive para enviar, consultar, atualizar e recuperar o arquivo de backup do banco de dados SQLite em uma pasta previamente configurada.

A integração depende da autorização concedida à conta Google utilizada pelo proprietário. Os arquivos são transferidos para a conta e a pasta de destino configuradas para essa finalidade.

Os dados do banco de dados podem conter informações registradas nas ordens de serviço. Portanto, o arquivo de backup deve ser tratado como contendo informações potencialmente pessoais.

### 4. Contas e compartilhamento

As contas Google utilizadas pelo proprietário pertencem a ele. O acesso à pasta de backup é controlado pelas permissões configuradas no Google Drive.

O aplicativo não vende dados, não utiliza os dados das ordens de serviço para publicidade e não os compartilha intencionalmente com terceiros. O armazenamento em nuvem é utilizado exclusivamente para a finalidade de backup e recuperação dos dados do sistema.

O tratamento técnico dos dados pela infraestrutura do Google continua sujeito aos termos e às políticas do próprio Google.

### 5. Armazenamento e segurança

Os dados operacionais são mantidos no banco de dados local do aplicativo. Os tokens de autorização do Google são armazenados no perfil local do usuário do Windows, conforme a implementação do programa.

O proprietário é responsável por controlar o acesso aos computadores, às contas Google e à pasta de backup, bem como por proteger os arquivos locais e as cópias armazenadas na nuvem.

### 6. Retenção e exclusão

Os dados locais são mantidos enquanto forem necessários para a operação do sistema. Os backups permanecem no Google Drive até que sejam substituídos ou excluídos pelo proprietário, conforme a rotina de backup utilizada.

A exclusão de um backup na nuvem não implica, necessariamente, a exclusão do banco de dados local.

### 7. Alterações nesta política

Esta política poderá ser atualizada quando houver mudanças relevantes no funcionamento do Sistema OS, nas permissões solicitadas ou na forma de armazenamento dos dados.

### 8. Contato

Para dúvidas sobre esta política ou sobre o tratamento dos dados pelo Sistema OS, entre em contato com o proprietário da Infocel Assistência Especializada, por meio dos canais de contato utilizados pela própria assistência técnica.
